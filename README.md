# 맛집기록 🍽

내가 다녀온 식당과 카페를 사진과 함께 기록하는 개인용 웹앱입니다.
폰 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

👉 **https://heun32.github.io/food-log/**

## 이런 걸 할 수 있어요

- **사진으로 가게 찾기**: 사진을 올리면 촬영 위치(또는 현재 위치) 근처의 음식점·카페 중 가장 가까운 곳을 "여기 맞나요?" 하고 물어봅니다. 맞으면 가게 이름·주소·전화번호·분류가 자동으로 채워집니다.
- **직접 검색**: 추측이 틀리면 가게 이름을 입력해 다시 찾을 수 있습니다.
- **영업시간·휴무·인스타 정리**: 네이버 지도, 카카오맵, 인스타 검색으로 바로 가는 버튼이 있어 확인한 내용을 붙여넣어 둘 수 있습니다. 다시 간 가게는 지난 기록에서 자동으로 가져옵니다.
- **달력 보기**: 다녀온 날짜 칸에 그날 사진이 동그랗게 표시됩니다. 하루에 여러 곳을 갔다면 그중 한 곳을 👑 대표 맛집으로 고를 수 있고, 같은 날 기록은 방문 시간순으로 보여줍니다.
- **별점·메모**: 먹은 메뉴나 분위기를 함께 남길 수 있습니다.

## 데이터는 어디에 저장되나요?

모든 기록과 사진은 **내 폰의 브라우저 안에만** 저장되며, 서버로 전송되지 않습니다.
그래서 브라우저 데이터를 지우면 기록도 함께 사라집니다. 설정(⚙)의 **백업 내려받기**로 가끔 백업해 두세요.

## 처음 쓸 때

1. 위 주소를 폰 브라우저로 엽니다. (아이폰은 Safari, 안드로이드는 Chrome)
2. 설정(⚙)에 카카오 개발자 사이트에서 받은 **JavaScript 키**를 넣습니다.
3. **홈 화면에 추가**한 뒤, 아이콘으로 실행합니다.
   아이폰은 아이콘으로 연 앱에서 키를 한 번 더 넣어야 합니다.

## 만든 방식

- HTML · CSS · JavaScript만으로 만든 웹앱(PWA)으로, 별도 서버 없이 GitHub Pages에서 무료로 운영됩니다.
- 가게 검색: 카카오 지도 JavaScript API
- 저장: 브라우저 IndexedDB
